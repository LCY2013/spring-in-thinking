# Spring 全家桶学习项目

一个全面的Spring生态系统学习仓库，涵盖了Spring Framework、Spring Boot、Spring Cloud、Spring Data以及响应式编程的所有方面。

## 📚 文档

- [English Documentation](README_EN.md) - 英文详细文档
- [中文详细文档](README_CN.md) - 中文详细文档

## 🎯 项目概述

本仓库旨在为Spring生态系统提供全面的学习材料和实践示例。从基础的Spring Framework概念到使用Spring Cloud的高级微服务架构，从Spring WebFlux的响应式编程到现代Spring Boot特性，应有尽有。

## 🏗️ 项目结构

```
spring-in-thinking/
├── spring-boot-projects/          # Spring Boot 综合示例
├── spring-cloud-projects/         # Spring Cloud 微服务
├── spring-cloud-alibaba-projects/ # Spring Cloud Alibaba 集成
├── spring-data-projects/          # Spring Data JPA 示例
├── spring-in-action/              # Spring Boot 实战示例
├── spring-in-reactive/            # Spring 响应式编程
├── spring-native/                 # Spring Native 示例
├── springcss-parent-pom/          # 微服务架构示例
├── thinking-in-spring/            # Spring Framework 核心概念
├── thinking-in-aop/               # 面向切面编程
├── thinking-in-spring-boot/       # Spring Boot 基础
├── thinking-on-spring/            # Spring 高级概念
└── mvnclean.sh                   # Maven 清理脚本
```

## 📦 主要模块

### Spring Boot 项目
[spring-boot-projects](https://github.com/LCY2013/spring-in-thinking/tree/master/spring-boot-projects) - Spring Boot 综合示例集合
- Web应用、REST API、数据访问、安全、缓存、消息队列等

### Spring Cloud 项目  
[spring-cloud-projects](https://github.com/LCY2013/spring-in-thinking/tree/master/spring-cloud-projects) - Spring Cloud 微服务架构
- 服务发现、配置管理、API网关、OAuth2、监控等

### Spring Cloud Alibaba
[spring-cloud-alibaba-projects](https://github.com/LCY2013/spring-in-thinking/tree/master/spring-cloud-alibaba-projects) - Spring Cloud Alibaba 集成
- Dubbo RPC、Nacos配置和发现

### Spring Data 项目
[spring-data-projects](https://github.com/LCY2013/spring-in-thinking/tree/master/spring-data-projects) - Spring Data JPA 高级示例
- JPA审计、EntityManager、动态查询等

### Spring 核心概念
[thinking-in-spring](https://github.com/LCY2013/spring-in-thinking/tree/master/thinking-in-spring) - Spring Framework 核心概念
- IoC容器、依赖注入、Bean生命周期、事件机制等

### 响应式编程
[spring-in-reactive](https://github.com/LCY2013/spring-in-thinking/tree/master/spring-in-reactive) - Spring 响应式编程
- Project Reactor、Spring WebFlux、RSocket等

### 其他模块
- [spring-in-action](https://github.com/LCY2013/spring-in-thinking/tree/master/spring-in-action) - Spring Boot 实战示例
- [thinking-in-aop](https://github.com/LCY2013/spring-in-thinking/tree/master/thinking-in-aop) - 面向切面编程
- [spring-native](https://github.com/LCY2013/spring-in-thinking/tree/master/spring-native) - Spring Native 示例
- [springcss-parent-pom](https://github.com/LCY2013/spring-in-thinking/tree/master/springcss-parent-pom) - 微服务架构示例

## 🚀 快速开始

1. **克隆仓库**
   ```bash
   git clone https://github.com/LCY2013/spring-in-thinking.git
   cd spring-in-thinking
   ```

2. **选择模块并运行**
   ```bash
   cd spring-boot-projects/spring-boot-with-web
   mvn spring-boot:run
   ```

## 📖 学习路径

1. **Spring核心** → **Spring Boot** → **Spring Cloud** → **响应式编程** → **高级特性**
2. 每个模块都包含详细的示例和注释
3. 建议按照模块顺序进行学习
